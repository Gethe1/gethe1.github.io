not signed in

Data comes straight from the Warcraft Logs API into this page. Your credentials and token are kept only in this browser's storage and never go anywhere else.

Option A · Sign in (hosted page)

Create a client at warcraftlogs.com/api/clients, tick Public Client, and set the redirect URL to:

This page is opened from disk, so sign-in can't redirect back. Host it (GitHub Pages, python -m http.server) or use option B.

Option B · Paste a token (works anywhere)

Make a normal (non-public) client, then run once:
curl -u CLIENT_ID:CLIENT_SECRET -d grant_type=client_credentials https://www.warcraftlogs.com/oauth/token
and paste the access_token value.

Share with people who have no API access

After saving an option B token, save a copy of this page with that token built in. Anyone with the copy only needs a report link. The token can read public logs only, but it is readable inside the file and uses your API allowance, so share the copy with people you trust and make a new one when it expires.
